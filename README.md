# کوئیز آنلاین - راهنمای راه‌اندازی

## این پروژه چیه؟
- `server.js`  : سرور (ثبت‌نام، ورود، بازی، لیگ جهانی). هیچ پکیج اضافه‌ای لازم نداره.
- `public/index.html` : خود بازی (همون طراحی قبلی، ولی وصل به سرور)
- `package.json`

نیازمندی: Node.js نسخه ۲۲.۵ یا بالاتر.

## اجرا روی کامپیوتر خودت (برای تست)
```
cd quiz-online
node --no-warnings server.js
```
بعد برو به http://localhost:3000

## گذاشتن روی اینترنت
1. پوشه را روی GitHub بگذار و به یک سرویس میزبانی Node.js وصلش کن (مثل Render، Railway، Fly.io).
2. دستور اجرا: `npm start`
3. **مهم:** دیتابیس یک فایل است (`data.db`). بعضی سرویس‌های رایگان بعد از هر ری‌استارت دیسک را پاک می‌کنند و همه‌ی حساب‌ها از بین می‌روند.
   یک Volume/Disk پایدار بگیر و مسیرش را در متغیر محیطی `DB_PATH` بگذار (مثلاً `/data/data.db`).
   شرایط رایگان هر سرویس را خودت چک کن، چون عوض می‌شود.
4. حتماً با HTTPS (همه‌ی این سرویس‌ها خودشان می‌دهند).

## برای APK
در `public/index.html` خط `const API_BASE = '';` را به آدرس سرورت تغییر بده:
`const API_BASE = 'https://اسم-سرور-تو.onrender.com';`
آدرس باید HTTPS باشد (اندروید HTTP ساده را به‌صورت پیش‌فرض می‌بندد).

## چه چیزهایی امن شده؟
- نام یکتاست (حروف بزرگ/کوچک، «ي/ی» و «ك/ک» و فاصله هم یکی حساب می‌شوند)
- رمز هرگز ذخیره نمی‌شود؛ فقط هش scrypt با salt جدا برای هر کاربر
- بعد از ورود، یک توکن تصادفی به دستگاه داده می‌شود
- سوال‌ها و جواب‌ها فقط روی سرورند و امتیاز را سرور حساب می‌کند. با DevTools نمی‌شود امتیاز جعلی ثبت کرد
- محدودیت تلاش برای ثبت‌نام و ورود (جلوگیری از حدس زدن رمز)
- نام‌ها در لیگ با textContent نمایش داده می‌شوند (جلوگیری از تزریق کد)

## محدودیت‌های فعلی
- فراموشی رمز: راه بازیابی ندارد (چون ایمیل نمی‌گیریم). اگر لازم شد باید دستی از دیتابیس حذف شود.
- لیگ ۱۰۰ نفر اول را نشان می‌دهد و رتبه‌ی خود بازیکن را هم اگر بیرون از آن باشد.
- بانک سوال داخل `server.js` است. سوال‌های بیشتر را همان‌جا اضافه کن.
